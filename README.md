# 🎤 Karaoke — локальное караоке на Python

Ищешь песню на YouTube, приложение само скачивает её, вырезает голос нейросетью Demucs,
подтягивает синхронизированный текст с LRCLIB и анализирует мелодию. Потом поёшь под минус
с бегущим текстом и нотной дорожкой, микрофон записывается, а в конце получаешь баллы.

Всё бесплатно и работает локально.

## Установка (Windows)
1. Установи **Python 3.11 или 3.12** с python.org (галочка «Add Python to PATH»).
2. Запусти **install.bat**: он поставит ffmpeg, Deno (нужен yt-dlp для YouTube), PyTorch
   (с CUDA, если есть видеокарта NVIDIA), Demucs и остальное. Первый раз займёт 5–15 минут.
3. Запускай **run.bat**.

Если YouTube перестал скачивать, запусти **update.bat** (обновляет yt-dlp).

## Как пользоваться
- Вводишь «исполнитель название», жмёшь «Найти», потом «+ Добавить» у нужного видео.
  Лучше выбирать версии «Official Audio» или «Lyrics», где нет длинного вступления как в клипе.
- Карточка покажет прогресс. На процессоре песня обрабатывается 1–5 минут, на видеокарте
  меньше минуты. При первом запуске Demucs скачает модель (~80 МБ).
- Кликаешь по готовой песне и жмёшь «Начать петь».

| Клавиша | Действие |
|---|---|
| Пробел | пауза / продолжить |
| ← → | перемотка на 5 секунд |
| [ ] | сдвинуть текст на 0.25 с, если он спешит или опаздывает (запоминается) |
| Esc | закончить и узнать баллы |

- «Голос артиста» подмешивает оригинальный вокал, если не помнишь мелодию.
- Правый клик по песне: найти текст заново (вручную уточнить исполнителя и название),
  обработать заново или удалить.

## Как считаются баллы
Из вырезанного вокала извлекается мелодия (алгоритм YIN). Во время пения так же определяется
высота твоего голоса, и каждый момент сравнивается с оригиналом. Октава не важна, так что
можно петь ниже или выше. Учитываются попадание в ноты (80%) и то, что ты поёшь там, где поёт
артист (20%). Записи сохраняются в `library/<id>/takes/`.

## Структура
```
main.py              запуск
app/youtube.py       поиск и скачивание (yt-dlp + ffmpeg)
app/separator.py     вырезание голоса (Demucs htdemucs)
app/lyrics.py        тексты с LRCLIB
app/pitch.py         определение высоты тона
app/scoring.py       подсчёт баллов
app/audio.py         воспроизведение и микрофон (sounddevice)
app/pipeline.py      фоновая обработка песен
app/ui/              интерфейс (PySide6)
library/             скачанные песни, минусы, тексты, записи
```
